# Da Mata Engenharia

Site institucional da Da Mata Engenharia — obras, reformas e vistorias.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Conteúdo oficial

Contato já cadastrado: WhatsApp, Instagram [@ddo_engpc](https://www.instagram.com/ddo_engpc/) e endereço em São Paulo.

Ainda podem ser preenchidos:

- `.env.local` para e-mail e horário de atendimento, se existirem
- `src/lib/data/projects.ts` com projetos reais
- `src/lib/data/testimonials.ts` com depoimentos autorizados
- `src/lib/data/before-after.ts` com fotos reais de antes e depois

A logo oficial está em `public/logo.png` (PNG transparente).
